# Emotion Detection Web Adaptation System

This project was developed as part of my undergraduate dissertation in Multimedia Software Development.

The system uses Python-based facial and vocal emotion detection to analyse a user's emotional state in real time. Based on the detected emotion, the application dynamically adapts website front-end elements such as colour schemes, interface styling, and user experience components to better suit the user's emotional needs.

## Features
- Facial emotion detection
- Vocal emotion detection
- Real-time emotion analysis
- Dynamic UI adaptation
- HTTP server integration for website communication
- Emotion tracking and data visualisation

## Technologies Used
- Python
- OpenCV
- Machine Learning / Emotion Recognition Models
- HTTP Server
- Front-end Web Technologies
